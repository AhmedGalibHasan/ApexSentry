# 🚀 ApexSentry – 3D Coastal Defense Simulation

**ApexSentry** is a 3D coastal defense game developed using Python and OpenGL. The project simulates a coastal defense outpost where players control a cannon to defend against incoming hostile units.

Featuring real-time 3D rendering, interactive gameplay, multiple camera perspectives, and progressively challenging enemy waves, ApexSentry provides an immersive computer graphics experience.

## 🎮 Features

- **3D Environment:** OpenGL-powered coastal defense environment.
- **Interactive Cannon:** Move, rotate, and adjust cannon elevation.
- **Multiple Enemy Types:** Face different hostile units, including SWARM, ROCKET, and GLIDER.
- **Wave-Based Gameplay:** Survive increasingly challenging enemy waves.
- **Multiple Camera Modes:** Switch between first-person and third-person perspectives.
- **Auto Aim:** Enable automatic targeting assistance.
- **Rapid Fire:** Toggle an enhanced firing mode.
- **Mega Shot:** Unlock and use a special projectile.
- **Dynamic Environment:** Switch between dusk and alternate lighting modes.
- **Game Statistics:** Track shots, hits, kills, score, and remaining lives.
- **Pause and Restart:** Manage gameplay through interactive controls.

## 💻 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/ApexSentry.git
```

### 2. Navigate to the project directory

```bash
cd ApexSentry
```

### 3. Install dependencies

```bash
pip install PyOpenGL PyOpenGL_accelerate
```

### 4. Run the game

```bash
python ApexSentry.py
```

**Note:** A compatible OpenGL graphics environment and GLUT/FreeGLUT runtime are required.

## 🎯 Game Controls

| Key / Input | Action |
|---|---|
| SPACE | Start / Pause / Resume |
| W / A / S / D | Move cannon position |
| I / K | Adjust cannon elevation |
| J / L | Rotate cannon |
| V | Switch camera perspective |
| C | Toggle auto aim |
| F | Toggle rapid fire |
| T | Activate Mega Shot when available |
| P | Toggle environment lighting |
| Z / X | Adjust field of view |
| Arrow Keys | Rotate third-person camera |
| Left Mouse Button | Fire projectile |
| ESC | Return to menu / Exit |

## 🕹️ Gameplay Objective

Defend the coastal outpost against incoming hostile units.

- Eliminate enemies to increase your score.
- Protect the command pad and preserve your lives.
- Survive successive enemy waves.
- Use different camera perspectives and targeting modes to improve your defense.
